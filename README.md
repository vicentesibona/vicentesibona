## Proyectos destacados

### [Job Agent](https://github.com/vicentesibona/job_agent)

Sistema de postulación asistida por IA que busca ofertas de trabajo, las guarda
en una base local y genera un CV adaptado a cada cargo.

- Scraper de ofertas públicas de LinkedIn con guardado incremental en SQLite.
- Agente **redactor** y agente **auditor** con modelos distintos para evitar el
  sesgo de autoevaluación; ciclo de corrección sobre un grafo LangGraph.
- CV generado solo con experiencia real, con validaciones anti-invención y
  secretos fuera del contexto del LLM.
- Exportación a Markdown, HTML y PDF, más un visor local para comparar oferta y CV.

`Python` · `LangChain` · `LangGraph` · `LLM APIs` · `Ollama` · `SQLite`

### Bikefit mediante visión computacional

Trabajo de título del Magíster en Ciencia de Datos: estimación de keypoints y
ángulos articulares desde video de smartphone para recomendar ajustes de bicicleta.

- Dataset reproducible con 9 keypoints y 234 registros tras aumentación.
- Comparación de MediaPipe, MoveNet, YOLOv11 y YOLOv11 con fine-tuning usando OKS y MAE.
- El modelo ajustado alcanzó un OKS promedio de 0,9469 frente a 0,5895 del modelo base.

`Python` · `OpenCV` · `MediaPipe` · `MoveNet` · `YOLOv11`
